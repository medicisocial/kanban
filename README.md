# Medici Social — Kanban Board

A drag-and-drop Kanban board for social media content pipeline management.

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:5173 in your browser.

## Features

- 5 columns: Briefing, In Production, In Review, Scheduled, Posted
- Drag and drop cards between columns
- Filter by client, platform, and keyword search
- Expandable card editor modal
- Color-coded clients and priority tags
- Preloaded sample data on first visit
- Dark mode agency aesthetic
